# Context Efficiency Acceptance Scenarios

Evaluate the baseline and candidate with the same task, model/settings,
repository snapshot, tools, acceptance criteria, independent reviews and gates.
Use host counters including tool payloads, subagents, retries and available
cache accounting. Source-size differences are not billed-token measurements.
No live model benchmark has been performed for this instruction update.

| Request | Required outcome | Context/work to avoid |
| --- | --- | --- |
| Repair a bounded API validation bug | Correct response contract, negative authorization cases when relevant, regression evidence and persisted handoff | Full compliance audit, unrelated platform skills, repeated successful tests before another change |
| Audit an entire application | Applicability recorded for all 36 controls, original evidence and explicit unexecuted checks | Loading every technology playbook regardless of detected stack; losing control coverage to a summary |
| Change a material multi-role form | Authoritative values/order, accessibility, server validation, idempotency, recovery and FORM_INTELLIGENCE evidence | Reloading unrelated specialist catalogs or replacing exact reference values with a short paraphrase |
| Resume a task after compaction or another window's update | Reload current revision, reconcile changed evidence and continue the actual next deliverable | Replaying the full conversation; trusting stale summaries or reusing invalidated passes |
| Certify an L3+ release | Independent verifier, immutable candidate, source evidence, applicable reproduced checks and explicit promotion authorization | Treating the implementer's compact report as independent review; skipping fresh verification to save tokens |

Reject the optimization if it loses acceptance coverage, hides a blocker,
weakens independence, expands permissions, increases reproducible errors or
rework, or produces a different requested artifact. Report a tradeoff when
quality, total latency or cost do not improve together; do not promise universal
savings for a model family.
