# Cost, context and privacy

Read metadata, relevant files, dependencies and evidence progressively. Reuse only
unchanged observations; invalidate cache by artifact identity and host/registry expiry.
Share ore-context-efficiency policy. A handoff contains objective, requirements,
constraints, relevant paths, interfaces, dependencies, decisions, evidence,
acceptance, open risks and next action. Full transcripts require a demonstrated need.

Use ore-cost-controller's native reported counters; the router does not maintain
a second billing ledger. Estimated total cost is separate from reported host usage.
Budgets filter proposed operations when estimates are complete, otherwise block
budget-constrained proposals conservatively. They are advisory, never guaranteed
spend caps. Preserve validated work and ask for instructions before expanding limits.

The mod has no timer, polling process, provider endpoint or background agent.
No routing authorizes a new provider, tools or transmission of private source.
Stored decisions allowlist configuration/approval/cost metadata, excluding input
profiles, secrets, prompts, arbitrary telemetry and free text. Config identifiers
and policy preferences must be reviewed metadata and never contain credentials.

ore-guard, ore-gates and regulatory contracts stay authoritative. ore-autopilot
may consume recommendations but cannot expand permissions; ore-resume reads the
same project state; ore-departments uses compact scoped contracts. New controls
cannot weaken FDA Part 11 or FTC Safeguards evidence requirements.
