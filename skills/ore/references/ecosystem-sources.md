# Vetted Ecosystem Sources

Use primary documentation first. Repositories below are optional references or adapter candidates, not runtime dependencies. Before importing material, verify the current license and version, pin a commit/release, preserve attribution, and run ORE's own behavioral evaluations.

## Mobile

- Android architecture: <https://developer.android.com/topic/architecture> and recommendations: <https://developer.android.com/topic/architecture/recommendations>; core quality: <https://developer.android.com/develop/adaptive-apps/quality-guidelines/core-app-quality>; adaptive quality: <https://developer.android.com/docs/quality-guidelines/adaptive-app-quality>; Material Design: <https://m3.material.io/>.
- Official Android skills, Apache-2.0: <https://github.com/android/skills>.
- Now in Android reference app, Apache-2.0: <https://github.com/android/nowinandroid>.
- Focused Kotlin/Compose skills, Apache-2.0: <https://github.com/chrisbanes/skills>.
- Apple SwiftUI resources: <https://developer.apple.com/swiftui/resources/>; Human Interface Guidelines: <https://developer.apple.com/design/human-interface-guidelines/>; accessibility: <https://developer.apple.com/documentation/swiftui/accessibility-fundamentals>; App Review Guidelines: <https://developer.apple.com/app-store/guidelines/>; privacy manifests: <https://developer.apple.com/documentation/bundleresources/privacy-manifest-files>.
- SwiftUI Agent Skill, MIT: <https://github.com/twostraws/SwiftUI-Agent-Skill>. Its catalog links to independently licensed projects: <https://github.com/twostraws/swift-agent-skills>.
- Flutter architecture: <https://docs.flutter.dev/app-architecture>, accessibility: <https://docs.flutter.dev/ui/accessibility>, and AI tooling/persistent rules: <https://docs.flutter.dev/ai/tools>.
- Official Flutter plugins/skills, BSD-3-Clause: <https://github.com/flutter/agent-plugins>; Dart skills, BSD-3-Clause: <https://github.com/dart-lang/skills>; runnable samples: <https://github.com/flutter/samples> (verify per-file third-party asset/font licenses).
- Cross-platform device automation, Apache-2.0: <https://github.com/appium/skills>.

## Web, design and discovery

- Normative WCAG 2.2: <https://www.w3.org/TR/WCAG22/>; supporting techniques: <https://www.w3.org/WAI/WCAG22/Techniques/>.
- Core Web Vitals: <https://web.dev/articles/vitals>.
- React and web-design agent skills, MIT: <https://github.com/vercel-labs/agent-skills>.
- Design-system extraction for agent skills, MIT: <https://github.com/vercel-labs/design-systems-to-agent-skills>.
- Creative web skill repository, MIT: <https://github.com/MengTo/Skills>. Underlying libraries such as GSAP and Three.js retain their own licenses.
- Google Search Essentials: <https://developers.google.com/search/docs/essentials>, spam policies: <https://developers.google.com/search/docs/essentials/spam-policies>, SEO starter guide: <https://developers.google.com/search/docs/fundamentals/seo-starter-guide>, crawling/indexing: <https://developers.google.com/search/docs/crawling-indexing>, structured-data policies: <https://developers.google.com/search/docs/appearance/structured-data/sd-policies>, and AI features guidance: <https://developers.google.com/search/docs/fundamentals/ai-optimization-guide>.
- Cross-engine standards and controls: Robots Exclusion Protocol <https://www.rfc-editor.org/rfc/rfc9309.html>, Schema.org <https://schema.org/>, IndexNow <https://www.indexnow.org/documentation>, Bing Webmaster Guidelines <https://www.bing.com/webmasters/help/bing-webmaster-guidelines-30fba23a>, OpenAI publisher controls <https://help.openai.com/en/articles/12627856>, and Google crawler controls <https://developers.google.com/crawling/docs/crawlers-fetchers/google-common-crawlers>.
- Local technical SEO tooling, Apache-2.0 with separate trademark terms: <https://github.com/iannuttall/seo>.
- SEO/GEO/AEO orchestration references, MIT: <https://github.com/gaguero/seo-agent-skills> and <https://github.com/staksoft/geo-seo-aeo-skill>.

Do not import AGPL or unclear-license code into this Apache-2.0 package without an explicit licensing decision. Never translate a repository's marketing claims into ORE guarantees.
